# Rama `charter` — coordinación del proyecto

Esta rama **no contiene código** y **nunca se hace merge** con otra rama. Aquí viven la especificación, el plan, las tareas, los reportes y las revisiones del proyecto bajo el protocolo CHARTER.

- **Rutas:** cuando un documento menciona `ROSTER.md`, `metodologia/…`, `plantillas/…` o `estandares/…`, en esta rama están dentro de `kit/`.
- **Antes de leer:** `git pull --rebase`.
- **Escribe solo tus archivos** (tabla de dueños en `kit/metodologia/PROTOCOLO.md`). Commit `CHR: <ID> <acción> T-XXX`, luego `git pull --rebase` y `git push origin charter`. Nunca `--force`.
- **Nunca** escribas secretos ni datos reales aquí.

Empieza por `PROYECTO.md` y `TABLERO.md`.
