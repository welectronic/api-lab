# T-004 — Agregar GET /api/health/uptime con su test

## Objetivo
Que `GET /api/health/uptime` responda `200 {"uptimeSeconds": <entero ≥ 0>}` con el uptime del proceso, verificado por `npm test` sin bases de datos.

## Contexto (leer solo esto)
- `SPEC.md` → US4 (escenarios 1–3), RF-008, Casos borde (uptime)
- `ARQUITECTURA.md` → **C-004** y C-002
- `CONVENCIONES.md` y `TROPIEZOS.md`
- **Patrón de referencia a seguir:** la ruta `/health` de `routes/healthRoutes.js` y `tests/health.test.js`

## Archivos permitidos
- Modificar: `routes/healthRoutes.js` (solo agregar la ruta `/health/uptime`)
- Crear: `tests/health-uptime.test.js`
- **No tocar:** `app.js` (es de T-003), `README.md` y `.env.example` (T-005), `tests/health.test.js`, `server.js`, `config/`, `models/`, `package*.json`

## Contrato a respetar
```
GET /api/health/uptime
→ 200 OK
  Content-Type: application/json; charset=utf-8
  {"uptimeSeconds": <entero ≥ 0>}     // Math.floor(process.uptime())
```

## Criterios de aceptación
| # | Criterio | Cómo se verifica | Falla cuando |
|---|---|---|---|
| 1 | Cumple el contrato: 200, JSON, **solo** la clave `uptimeSeconds` | `npm test` | el test no compara status, `content-type` y `Object.keys(body)` igual a `['uptimeSeconds']` |
| 2 | El valor es entero y ≥ 0 | `npm test` | el test no usa `Number.isInteger` y `>= 0`, o el valor es decimal |
| 3 | El valor sale de `Math.floor(process.uptime())` | inspección del diff | usa `Date.now()` guardado al cargar el módulo, u otra fuente |
| 4 | Es monótono: dos consultas con ≥ 1 s entre ellas, la segunda no es menor | `npm test` | el test no existe o espera menos de 1000 ms |
| 5 | Corre sin MongoDB ni SQLite y el proceso termina solo | `npm ci && npm test` sin `.env` | importa `server.js`, queda colgado o no cierra el servidor |
| 6 | `GET /api/health` sigue igual y `tests/health.test.js` pasa | `npm test` | cambia la ruta `/health` o su respuesta |
| 7 | Sin dependencias nuevas y solo archivos permitidos | `git diff --stat origin/main...HEAD` | aparece otro archivo o cambia `package*.json` |
