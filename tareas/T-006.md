# T-006 — Instalar el CI de CHARTER (C-006) y probar sus casos de abuso

## Objetivo
Que todo PR a `main` pase por 4 checks bloqueantes con versiones fijas, y que cada caso de abuso falle en el check que le corresponde. El PR de esta tarea debe pasar.

- `CONVENCIONES.md` y `TROPIEZOS.md`

  - Crear `.github/workflows/charter-ci.yml`.
  - Crear `.github/scripts/charter-guardia.sh` (con permiso de ejecución: `git update-index --chmod=+x`).

## Contrato a respetar
Es **C-006** de `ARQUITECTURA.md`, tal cual. Resumen para no perderse:
- `on: pull_request` a `[main]`. Sin `workflow_dispatch`. `permissions: contents: read`.
- SHAs, versiones y digests **exactos** de C-006, con la etiqueta en un comentario. `persist-credentials: false` en todo checkout.
- Los 5 `name:` de job, **exactos**: `Guardia de ramas`, `Secretos (gitleaks)`, `Análisis estático (Semgrep)`, `Pruebas` y `Dependencias vulnerables (informativo)`.
- `secretos` agrega `--ignore-gitleaks-allow`; `sast` agrega `--disable-nosem`.
- `pruebas` no tiene `if:` y falla si la salida de `npm test` no contiene `# tests N` con N ≥ 1. Usa `set -o pipefail` para que no se pierda el exit de `npm test`.
- La guardia está en `.github/scripts/charter-guardia.sh` y el job solo la llama con `HEAD_REF` y `BASE_SHA`. Las reglas de salida son las de C-006.

**Secreto sintético (A3/A4):**
- Lo generas al momento con 32 caracteres aleatorios, con una forma que detecte una regla de gitleaks v8.28.0 (por ejemplo `api_key = "<valor>"`, regla `generic-api-key`).
- No puede terminar en `EXAMPLE` ni tener el formato de un proveedor real (`AKIA…`, `ghp_…`, `sk-…`), porque GitHub push protection podría bloquear el push.
- **Nunca lo escribas en `charter`** ni en el reporte: descríbelo como "generic-api-key sintético de 32 caracteres".
- Queda publicado para siempre en `refs/pull/N` del repo público (D-1). Por eso debe ser inventado.

**L-1 (límite documentado, no se prueba):** un PR que edita el workflow puede ponerlo en verde. Lo controla el LIDER en `revisar`, leyendo el diff de `.github/`.
