# Tarjetas de rol

Cada instancia lee **su tarjeta de rol** y, si la tarea le asigna una función (probar, depurar, pre-revisar o una lente del consejo), también la **tarjeta de esa función**. La tarjeta dice qué puede hacer, qué no y cuándo escalar. Si la tarjeta y una instrucción se contradicen, gana la tarjeta y se escala al LIDER.

| Tarjeta | Tipo |
|---|---|
| `LIDER.md` | Rol |
| `SENIOR.md` | Rol (SENIOR-1, SENIOR-2, SENIOR-3) |
| `RAPIDO.md` | Rol |
| `PROBADOR.md`, `DEPURADOR.md`, `PRE-REVISOR.md` | Función (la asume un rol según la tarea) |
| `lentes/*.md` | Lente del consejo de diseño |
